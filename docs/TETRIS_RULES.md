# ゲームルール仕様（Python / TypeScript 共通）

Python 版エンジン（`backend/games/tetris/`）と TypeScript 版エンジン（`frontend/src/games/tetris/engine/`）は
**この仕様に従って同じ動きをする**。どちらかを変えたら、もう片方も変え、
`shared/fixtures/tetris/` を作り直してから両方のテストを通すこと（手順は末尾）。

## 盤面
- 幅 10、高さ 40。**y は下から上**（y=0 が最下段）。x は左から右。
- 見える範囲は y=0..19。y=20..39 は画面外のバッファ。
- 1 行は 10bit の整数で表す（bit x が 1 ならそのマスが埋まっている）。

## ミノ（SRS）
- 種類は `I J L O S T Z`。回転状態は `0`（出現時）、`1`（R, 右回転後）、`2`、`3`（L）。
- 形は「原点からの相対セル座標 (dx, dy)」で定義する（`pieces.py` / `pieces.ts`）。
- 出現位置は原点 (x=4, y=20)、回転状態 0。
  出現位置でぶつかる場合はゲームオーバー（block out）。
- 回転は SRS の壁蹴り（kick）表を使い、テストを 0〜4 の順に試す。180°回転はない。
- 固定したミノが見える範囲より上（y>=20）にはみ出しても、それだけではゲームオーバーにしない（lock out なし。jstris と同じ）。
  次のミノが出現位置でぶつかったときに block out で終わる。

## 操作
| 操作 | 意味 |
|---|---|
| `L` / `R` | 左右に 1 マス移動 |
| `CW` / `CCW` | 右回転 / 左回転 |
| `SD` | ソフトドロップ（1 マス下へ） |
| `SDB` | ソフトドロップで床まで落とす（固定はしない） |
| `HD` | ハードドロップ（床まで落として固定） |
| `HOLD` | ホールド（1 回固定するまで 1 度だけ） |

重力とロック遅延は **時間に依存するのでエンジンには含めない**。
ブラウザ側の `GameController`（`frontend/src/games/tetris/engine/controller.ts`）が担当する。

## ツモ（乱数）
- 乱数は mulberry32（32bit）。`seed` から決定的に同じ順番になる。
- 7 種 1 巡（7-bag）。1 袋ごとに Fisher–Yates でシャッフル（i=6→1、j = floor(rand()*(i+1))）。
- ネクストは 5 個表示。
- せり上がりの穴の列は、別の乱数（seed = `seed ^ 0x9E3779B9`）で決める。

## T-Spin 判定
固定した瞬間に次をすべて満たすと T-Spin。
1. T ミノである。
2. 最後に成功した操作が回転である。
3. T の中心を囲む 3×3 の四隅のうち 3 つ以上が埋まっている（壁・床の外も「埋まっている」とみなす）。

そのうえで、T が向いている側の 2 隅（front corners）が両方埋まっていれば **T-Spin**、
そうでなければ **T-Spin Mini**。ただし最後の回転が kick テスト 4 番（5 番目）で成功していた場合は、
Mini ではなく T-Spin とする。

| 回転状態 | front corners (dx, dy) |
|---|---|
| 0（上向き） | (-1,+1), (+1,+1) |
| 1（右向き） | (+1,+1), (+1,-1) |
| 2（下向き） | (-1,-1), (+1,-1) |
| 3（左向き） | (-1,+1), (-1,-1) |

## 火力（相手に送る段数）
| 消し方 | 0 列 | 1 列 | 2 列 | 3 列 | 4 列 |
|---|---|---|---|---|---|
| 通常 | 0 | 0 | 1 | 2 | 4 |
| T-Spin Mini | 0 | 0 | 1 | - | - |
| T-Spin | 0 | 2 | 4 | 6 | - |

- **Back-to-Back (B2B)**：テトリスか、列を消した T-Spin（Mini を含む）を「難しい消し方」とする。
  直前の消去も難しい消し方だったとき +1。難しくない消し方で列を消すと B2B が切れる
  （列を消さない T-Spin では切れない）。
- **REN（combo）**：列を消すたびに combo が +1（最初の消去で 0）。消さずに固定すると -1 に戻る。
  ボーナスは `[0,0,1,1,1,2,2,3,3,4,4,4,5]` を combo で引く（13 以上は 5）。
- **パーフェクトクリア**：消去後に盤面が空なら +10。

## せり上がり（おじゃま）
- 受け取った段数は「予告（pending）」に積まれる。
- 列を消して火力が出たときは、まず予告を相殺し、残りを相手に送る。
- 列を消さずに固定したときは、予告を最大 8 段まで盤面の下から入れる。
  予告 1 件ごとに穴の列を 1 つ決め、その件の段はすべて同じ列に穴があく。
- せり上がりで y>=40 にブロックが押し出されたらゲームオーバー（top out）。

## 仕様を変えたときの手順
1. `backend/games/tetris/` を直す。
2. `frontend/src/games/tetris/engine/` を同じように直す。
3. `cd backend; python -m games.tetris.fixtures` で `shared/fixtures/tetris/engine_cases.json` を作り直す。
4. `cd backend; pytest` と `cd frontend; npm test` の両方を通す。
