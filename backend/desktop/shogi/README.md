# desktop/shogi/ 将棋 AI のデスクトップアプリ

学習した将棋 AI（`rl/shogi/`）と、手元のパソコンで対局するアプリ。Django もブラウザも使わず、
AI はこのアプリの中で GPU を使って直接考える（サーバーとの通信の待ちが無く、先読みもできる）。

## 起動
```powershell
cd backend
.\.venv\Scripts\python -m desktop.shogi                    # 起動
.\.venv\Scripts\python -m desktop.shogi.install_shortcut   # デスクトップに「将棋 AI」のショートカットを作る
```
ショートカットは `pythonw.exe`（黒い窓を出さない Python）で起動する。エラーは `backend/logs/shogi_desktop.log` に残る。
学習済みのネット（`runs/shogi/<名前>/checkpoints/best.pt`）が 1 つも無いと AI は動かない（`rl/shogi/README.md` の手順で学習する）。

## できること
- 先手・後手を選んで対局。クリックで駒を選び、点の出たマスをクリックで指す。持ち駒は盤の下の駒をクリック
- 強さ: 1 手に使う時間（30 秒〜0.5 秒）か、読む回数（1000 回・100 回・読まない）で選ぶ
- **先読み**: あなたが考えている間も AI が読み続ける。あなたが指した手の先の読みは、AI の番にそのまま使われる
  （AI の 10 秒 + あなたの考慮時間ぶん読んでいることになる）。回数で決める弱い設定では先読みしない
- AI の読み: AI から見た勝率・評価値・読み筋（「あなたの手の予想」も）・読んだ局面数、勝率のグラフ
- 詰みは別プロセスで df-pn が探している。見つかれば「詰みを読み切りました」と出て、その手順で指す
- 待った・投了・入玉宣言・盤の反転。千日手・連続王手の千日手も判定する。AI は勝率 1% を切ると投了する

## ファイル
| ファイル | 中身 |
|---|---|
| `__main__.py` | 起動（Qt のアプリを作ってウィンドウを出す） |
| `window.py` | メインウィンドウ（設定・AI の読みの表示・棋譜・勝率グラフ） |
| `board_view.py` | 盤と駒の描画、クリックで指す操作（駒は五角形を描いて漢字を書く。画像は使わない） |
| `game.py` | 対局の進行（指し手・待った・終局の判定）。Qt にも AI にも依存しない |
| `engine.py` | AI を別スレッドで動かす（考える・先読み・止める）。使うネットの一覧と強さの設定（`LEVELS`） |
| `install_shortcut.py` | デスクトップのショートカットとアイコン（`shogi.ico`）を作る |

## 直すときの注意
- Qt の部品は画面のスレッドからしか触れない。AI のスレッドからは `window.Bridge` のシグナルで渡す
- 新しい対局・待ったのたびに `game_no` を増やし、それより前に考え始めた AI の結果は捨てる
- 既定で使う AI は `engine.PREFERRED`（対局で一番強かったもの）。学習中の run は一覧の最後に回る
- 探索そのもの（速さ・詰み探索・木の使い回し）は `rl/shogi/mcts.py`。サーバー（`apps/shogi`）と共通
