# rl/racer/ レース AI の学習（PyTorch・CPU）

物理は `games/racer/physics.py`（ブラウザ版 `frontend/src/games/racer/engine/physics.ts` と同じ式。
`python -m games.racer.fixtures` のテストデータで一致を確認）。

## 学習の流れ
1. **模倣学習**（`--bc-steps`）: 学習なしの運転者（`physics.py` の `heuristic_action`。先の中心線へ
   ステアを切り、コーナーの手前で減速する）の操作をまねる。「とりあえずコースに沿って走る」を
   先に覚えさせる。ゼロから試行錯誤させると、壁にぶつかって止まるばかりで 1 周できない。
2. **PPO（強化学習）**: 256 面を同時に走らせて経験を集める。報酬は

   | 出来事 | 報酬 |
   |---|---|
   | 前へ 1m 進む | +1（後ろへ下がるとさらに −2/m） |
   | 壁に当たる（1 ステップ） | −0.25 |
   | コースから落ちる | −40 |
   | 空中で半回転して着地する（トリック） | +6 |

   まねただけでは通らない攻めたライン取りや、ジャンプ台での飛び方を自分で見つけていく。
3. AI は 1/30 秒ごとに「アクセル・ステア・ジャンプ」の 3 つを決める。観測は 30 個
   （自分の速度と姿勢、中心線からのずれ、この先 6 か所のコースの形と高さ、この先 40m の仕掛け）。

レースには対戦相手がいない（速く走れば勝ち）ので、エアホッケーのような自己対戦は要らない。
そのぶん学習は素直で速い。

3 つのコースと 3 つの車を混ぜ、開始位置と開始速度もばらばらにして学習させる。
1 つの方策でどのコースのどの車でも走れるようになり、後半のコーナーも均等に練習できる
（毎回スタート地点からだと、最初のコーナーばかり上手くなってしまう）。

| ファイル | 中身 |
|---|---|
| `policy.py` | 方策と価値のネット（小さな MLP）、ブラウザ用の JSON 書き出し |
| `env.py` | 学習用の環境（N 面同時・コースと車の混ぜ方）、評価用の `evaluate()` |
| `train.py` | 模倣学習 + PPO |

```powershell
cd backend
.\.venv\Scripts\python -m rl.racer.train --run-name v1 --iterations 1500
.\.venv\Scripts\python manage.py sync_runs      # 結果を強さページに取り込む
```
動作確認だけなら `--iterations 6 --envs 64 --steps 64 --bc-steps 400 --eval-every 3`（1 分ほど）。

### 実測（i7-11700F・CPU のみ）
1 イテレーションあたり約 1.6 秒（約 21,000 ステップ/秒）。1500 回で約 40 分。
模倣学習 300 回 + PPO 10 回（25 秒）の時点で、すでに 3 コースすべてで学習なしの運転者より速くなった
（`score` 1.02）。そこから 125 回で 1.048 まで伸び（落下は 0 のまま）、そのあとは少しずつ下がって 250 回で 1.022 になった。
探索のばらつきが小さくなりすぎて、いったん固まった走り方から抜け出せなくなるためと思われる。
配られるのは `best.json`（いちばん速かった 125 回目）なので、遊ぶぶんには問題ない。
もっと伸ばしたいなら `--entropy` を上げる（探索を増やす）か、`--lr` を下げて長く回す。

この重み（125 回目）をブラウザ側の計算で走らせた実測:
desert 24.5s / meadow 19.5s / neon 19.4s（学習なしはそれぞれ 25.6s / 20.4s / 20.7s）。

AI はトリック（空中での半回転）をほとんど決めない。回しているあいだは着地が乱れて遅くなるので、
「速く走る」ことを目指すと自然にそうなる。派手に飛ばせたいなら `env.py` の `R_TRICK` を上げる
（ただし上げすぎると、タイムを捨てて回るだけの AI になる）。

## 評価
25 イテレーションごとに、全コースを 1 周走らせて学習なしの運転者とタイムを比べる。
`score` は「学習なしのタイム ÷ AI のタイム」の全コース平均で、**1.0 を超えたら AI のほうが速い**。
`evals.jsonl` の `results` にはコースごとの `lap_sec` / `heuristic_sec` / `ratio` / `falls` / `tricks` が入り、
強さページ（`frontend/src/games/racer/pages/RacerStatsPage.tsx`）がそのまま読む。

## ブラウザでの動き
方策の重み（JSON）を `GET /api/racer/agents/<id>/policy/` で配り、ブラウザで計算する。
学習した AI が学習なしの運転者より速くなる（`score > 1.0`）までは学習なしが既定になる
（`apps/racer/agent_registry.py`）。

## コースや車を足したとき
`shared/courses/` や `shared/cars/` に足しただけで、次の学習から自動で対象に入る（`env.py` が全部読む）。
ただし観測の形（`physics.py` の `OBS_DIM`）を変えたときは `policy.py` の `POLICY_VERSION` を上げること。
古い重みは読めなくなる。
